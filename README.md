One line, 184 characters: the elevator pitch a city pigeon gives investors for its delivery startup — wings, not wheels, zero fuel, zero traffic, and couriers that literally poop on the competition; seed round open, coo if you're in.

## Run it

```sh
python3 main.py
```

It validates the line (one sentence, 1–200 characters) and writes it to `/output/entry.txt`.
